# Sri Lankan IT Career Guide

A project to help Sri Lankan students, graduates, and job seekers identify suitable IT career paths based on their skills, interests, academic background, and local market demand.

## Project goal

The system will evaluate a user profile, compare it with common IT job roles in Sri Lanka, identify skill gaps, and recommend a suitable career path and learning roadmap.

## Current phase

Weeks 3–4 implementation focus:

- requirements analysis
- user and stakeholder needs
- IT role and skill taxonomy
- data model definitions

## Repository structure

- `docs/requirements.md` – functional and non-functional requirements
- `docs/skill-role-mapping.md` – career-role skill mapping and data analysis
- `data/it_career_roles.json` – starter dataset for role definitions and competency weights

## Project scope summary

- Personalized IT career recommendation
- Skill-gap analysis
- Career path suggestions
- Learning roadmap guidance
- Local market relevance for Sri Lanka

## Next steps

1. Finalize the requirement specification.
2. Validate the role taxonomy with stakeholders.
3. Prepare the recommendation logic and scoring model.
4. Move into system design and development.
